# DRIVE THEORY SWITZERLAND

App de estudo (PWA) para o exame teórico de base suíço, categoria B, em português, com os termos oficiais em francês.

- `docs/SPEC.md`: requisitos, modelo de dados, stack
- `docs/BOARD.md`: tarefas, dependências, modelos, status
- `docs/DECISIONS.md`: decisões registradas
- `docs/SOURCES.md`: fontes e data de verificação
- `legal/rules/`: regras com trecho literal do Fedlex
- `questions/`: perguntas originais (nunca cópias da ASA nem do iTheorie)
- `app/`: PWA
- `scripts/`: verificações automáticas
